# Suraj Electricals — Website design

Live: https://www.surajelectricals.com

I designed this site for Suraj Electricals, an electrical panel manufacturer based in Gurugram. I built it from scratch with a custom design, animations, and no frameworks.

## What I built

- A custom dark navy + copper color scheme (copper because that's literally what busbars/wiring are made of)
- An animated hero section with an SVG circuit trace in the background
- Scroll animations, a count-up stats section, and an animated "build process" timeline
- A responsive nav with a mobile menu, an infinite scrolling client logo strip, and a testimonial slider
- Fully responsive across devices

## Built with

Plain HTML, CSS, and JavaScript. No frameworks, no build tools — just files you can open directly in a browser.

## Structure

```
index.html            → homepage
about.html, contact.html, products.html, projects.html, gallery.html, management.html
power-control-centres.html, motor-control-centres.html, capacitor-panels.html, amf-panels.html
css/modern.css         → all the styling
js/modern.js           → animations, nav behavior, slider logic
images/                → product, project, and client photos
```
